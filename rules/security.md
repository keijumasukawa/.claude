# セキュリティ規程

機密情報・個人情報の取り扱いとアクセス制御を対象とし、言語・フレームワークを問わず適用する。

## 方針

- 機密情報・個人情報を、ソースコードに含めない。
- 機密情報は環境変数で管理し、実際の値を含むファイル(`.env`、`.env.local` 等)はバージョン管理の対象外とする。
- 必要な環境変数は `.env.example` に列挙し、実際の値は書かない。
- 誤ってコミットした場合は作業を中断し、直ちに利用者へ報告する。

例示には次の代替値を用いる。

| 対象 | 代替値 |
| --- | --- |
| 氏名 | 中立なダミー名 |
| メールアドレス | `you@example.com` |
| ドメイン | `example.com` |

## 認可

- 認可判定はクライアント側の制御に依存させず、必ずサーバー側で行う。
- 外部入力は全て信頼せず、スキーマ検証を経て使用する。
