# 文書規程

作成する全ての文書に適用する。文書の種類ごとの様式は、各規程及びスキルに定める。

## 記述言語

- 利用者向けの説明・報告及び文書は日本語とする。
- 識別子・型名・ファイル名は英語とする。
- コード中のコメントは日本語とする。可否及び命名の書式はコーディング規程による。

## 文体

- 意味を保ったまま最小限の文字数で記述する。
- 常体とし、口語的な表現を用いない。
- 文には「。」を付ける。体言で終わる項目・表内・見出し・タイトルには付けない。

## 表記

- 接続詞は仮名で書く。ただし「及び」「並びに」「又は」「若しくは」は漢字とする。
- 形式名詞(こと、とき、ところ、もの、ため、とおり、ほか)及び補助動詞は仮名で書く。
- 副詞の「全て」及び例示の結びの「等」は漢字とする。
- 数量は算用数字とし、訓による数え方は漢数字とする。
- 読点は「、」、句点は「。」とする。
- 括弧は半角の () と「」を用いる。

## 構造

- 見出しは、主題を `#`、区分を `##` とし、階層は2段までとする。
- 主題の直下に、その文書の対象と適用範囲を1文で示す。
- 規則・要件は箇条書きで列挙し、段落で列挙しない。
- 箇条書きの項目には一つの規則を記述し、補足は同一項目に続ける。入れ子は1段までとする。
- 手順は番号付きの箇条書きとし、実行順に記述する。
- 三つ以上の対象を同じ観点で比較する場合は表とする。表の各セルは体言で記す。
- 段落は、前置きに限る。
- 規則に理由を付さない。
- コマンド・設定・雛形はコードブロックに置き、言語を指定する。
- 同一リポジトリ内の文書・雛形への参照はリンクとする。
- 記入できない節・表は設けない。記入できるようになった時点で追加する。
