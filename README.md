# .claude

Claude Code の利用者スコープ設定を管理するリポジトリ。`~/.claude` に配置する。

## 目的

全プロジェクト共通の規程と設定を利用者スコープへ集約し、各プロジェクトのリポジトリに Claude 関連ファイルを持たせない。

## 構成

| 対象 | 内容 |
| --- | --- |
| `CLAUDE.md` | 全体に適用する原則 |
| `rules/` | 個別の規程 |
| `skills/` | 定型手順のスキル |
| `hooks/` | フックから呼び出す検査スクリプト |
| `settings.json` | 権限・フック・属性表示の設定 |

## 管理対象

`.gitignore` は既定で全てを除外し、管理対象のみを明示的に許可する。管理対象を増やす場合は `.gitignore` に許可する行を追加する。

## 規程の変更

変更は本リポジトリで行い、各マシンでは `git pull` で取り込む。各プロジェクトのリポジトリには、固有の事項のみを `<project>/CLAUDE.md` に記載する。
