name: update-readme
description: README.md の変更を単独のプルリクエストで行う。README の修正・追記を行うときに使用する。
---

README.md を次の手順で変更する。

1. 最新の `main` から `docs/readme` ブランチを作成する。名称は毎回これを使い回す。
2. README.md のみを変更し、メッセージ `docs: README を修正` でコミットする。他のファイルを含めない。
3. push し、タイトル `docs: README を修正` でプルリクエストを作成する。Issue は伴わない。本文はテンプレートの全項目を次の内容で簡素に埋め、詳述しない。
   - 目的: README の更新
   - 変更内容: README の更新
   - 確認方法: リポジトリのトップページでの表示確認
4. レビュー待ちである旨を報告して作業を終える。

記載規則:

- 内容の記載は [README.md](README.md) を雛形とする。
- 記入できない節は設けない。記入できるようになった時点で追加する。
