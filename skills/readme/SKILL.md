description: README.md の追加・修正を単独のプルリクエストで行う。README を作成・変更するときに使用する。
---

README.md を次の手順で変更する。`<動作>` は、新規に作成する場合は「追加」、既存を変更する場合は「修正」とする。

1. タイトル `README を<動作>` で Issue を作成する。本文はテンプレートの全項目を次の内容で簡素に埋め、詳述しない。
   - 目的: README の<動作>
   - 内容: README の<動作>
2. 最新の `main` から `docs/readme` ブランチを作成する。名称は毎回これを使い回す。
3. README.md のみを変更し、メッセージ `docs: README を<動作>` でコミットする。他のファイルを含めない。
4. push し、タイトル `docs: README を<動作>` でプルリクエストを作成する。本文はテンプレートの全項目を次の内容で簡素に埋め、詳述しない。
   - 目的: README の<動作>
   - 内容: README の<動作>
   - 確認方法: リポジトリのトップページでの表示確認

記載規則:

- 内容の記載は [README.md](README.md) を雛形とする。
- 公開デモがある場合は、URL をリポジトリの About に記載し、冒頭の説明でその所在を示す。
- 雛形にない節の追加や構成の変更は、利用者に確認する。
