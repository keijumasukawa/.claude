---
name: release
description: リリースを作成する。バージョンを更新して公開するときに使用する。
---

リリースを次の手順で作成する。

1. バージョンを更新し、プルリクエストで登録する。管理場所はプロジェクトの構成による。
2. マージ後、リリースノートを [RELEASE.md](RELEASE.md) を雛形に作成し、タグ名とともに全文を提示する。
3. 承認を得たのち、次のコマンドを提示する。実行は利用者が行う。

```bash
gh release create v<バージョン> --title v<バージョン> --notes "<リリースノート>"
```
